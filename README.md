# Pixel Quest: Echoes of Fate - JRPG Retro

¡Bienvenido a **Pixel Quest: Echoes of Fate**!

Este paquete contiene el juego completo con todos los recursos de alta resolución, modelos pixel art de héroes y enemigos, fondos de arena de batalla, efectos de sonido y todas las interfaces 100% centradas.

---

## 🚀 Cómo Iniciar el Juego en Visual Studio Code

### Opción 1: Con Python (Recomendado y más rápido)
Abre la terminal en la carpeta del juego y escribe:
```bash
python main.py
```
*(O simplemente haz doble clic en `iniciar_juego.bat` en Windows)*.

Se abrirá automáticamente una pestaña en tu navegador web con la versión completa del juego, todas las animaciones, modelos y efectos.

---

### Opción 2: Con Node.js / NPM (Entorno de desarrollo)
Si deseas modificar el código fuente en `src/`:
```bash
npm install
npm run dev
```

---

## 🎮 Características del Juego
- **Combate Táctico por Turnos**: Acciones directas, habilidades por clase, objetos y huida táctica.
- **Interfaces Centradas**: Consola de mandos, modales de habilidades y mochila situados en el medio de la pantalla.
- **Modelos Gráficos en Alta Resolución**:
  - Héroes: Guerrero, Mago, Pícaro, Clérigo y Paladín.
  - Enemigos: Limo Verde, Murciélago Vampírico, Duende Minero, Caballero Esqueleto, Diablillo del Vacío, Rey Gelatinoso (Jefe) y Dragón Volcánico (Jefe).
- **Fondos de Escenarios**: Cripta Subterránea, Bosque Místico y Santuario del Dragón.
- **Efectos de Sonido Sintetizados**: Audio espacial retro mediante Web Audio API (no requiere archivos externos).
- **Exploración por Nodos**: Descubre cofres, santuarios sagrados y celdas de rescate de aliados cautivos.
